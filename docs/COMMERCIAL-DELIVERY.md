# Commercial Delivery Checklist

## Included
- Full application source
- Database migrations
- Docker and hosted deployment guidance
- Environment variable template
- Sector presets
- White-label configuration
- Security and privacy guidance
- Test and smoke-test procedure
- MIT license and upstream attribution

## Buyer handoff
1. Clone or download the source.
2. Configure the environment in the deployment system.
3. Configure the database and apply migrations.
4. Configure the AI and messaging providers.
5. Connect the business calendar.
6. Select a sector preset.
7. Configure business identity, logo, colors, assistant persona, services, staff, and hours.
8. Run health checks and the smoke-test suite.
9. Verify webhook validation, booking conflicts, tenant isolation, and human escalation before production use.

## Licensing
Retain the upstream MIT license and attribution. Do not describe upstream code as written from scratch. Product-specific modifications and documentation are part of the commercial package.
